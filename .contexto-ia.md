## 🔌 Padrão de Conexão com o Banco (CRÍTICO)

### Como funciona
O `Model/conexao.php` cria **uma única instância PDO global** chamada `$conexao`:
```php
// Model/conexao.php
require_once __DIR__ . "/../bootstrap.php";
$conexao = new PDO(
    "mysql:host=" . $_ENV['DB_HOST'] . ";dbname=" . $_ENV['DB_NAME'] . ";charset=utf8",
    $_ENV['DB_USER'],
    $_ENV['DB_PASS'],
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);
```

### Padrão dos Controllers (seguir sempre este modelo)
```php
// Exemplo: CadastroEmpresaController.php
require_once __DIR__ . "/../Model/conexao.php";
require_once __DIR__ . "/../Model/Database/Empresa.php";

class CadastroEmpresaController {
    private $empresa;

    public function __construct() {
        global $conexao; // pega a conexão global
        $this->empresa = new Empresa($conexao); // injeta no Model (Injeção de Dependência)
    }
}
```

### Padrão dos Models (seguir sempre este modelo)
```php
// Exemplo: Empresa.php
class Empresa {
    private $pdo;

    public function __construct($pdo) {
        $this->pdo = $pdo; // recebe a conexão injetada, não cria ela própria
    }

    public function listarDadosEmpresa(): array {
        $sql = $this->pdo->prepare("SELECT * FROM empresa ORDER BY nome_fantasia");
        $sql->execute();
        return $sql->fetchAll(PDO::FETCH_ASSOC);
    }
}
```

> **⚠️ NUNCA** use `new PDO(...)` diretamente dentro de um Model. O PDO é criado em `conexao.php` e **injetado** via `__construct($pdo)`.

## 🗄️ Banco de Dados: Tabelas Principais

### Tabela `projeto` (módulo do Matteus)
```sql
CREATE TABLE IF NOT EXISTS projeto (
  id                INT NOT NULL AUTO_INCREMENT,
  empresa_id        INT NOT NULL,           -- FK → empresa.id
  modelo_pentest_id INT NOT NULL,           -- FK → modelo_pentest.id
  nome              VARCHAR(80) NOT NULL,
  data_inicio       DATE DEFAULT NULL,
  data_fim_prevista DATE DEFAULT NULL,
  data_fim_real     DATE DEFAULT NULL,
  horas_contratadas DECIMAL(8, 2) NOT NULL DEFAULT 0.00,
  horas_executadas  DECIMAL(8, 2) NOT NULL DEFAULT 0.00,
  tipo              ENUM('BLACK BOX', 'GRAY BOX', 'WHITE BOX') NOT NULL,
  nivel_sigilo      ENUM('INTERNO', 'EXTERNO') NOT NULL,
  status            ENUM('AGUARDANDO', 'EM_ANDAMENTO', 'PAUSADO', 'CONCLUIDO', 'CANCELADO') NOT NULL DEFAULT 'AGUARDANDO',
  escopo            TEXT NOT NULL,
  alvo              TEXT NOT NULL,
  contrato          VARCHAR(255) DEFAULT NULL,
  restricao         TEXT,
  habilitado        TINYINT NOT NULL DEFAULT 1,
  created_at        TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at        TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (id)
);
```

### Outras tabelas relevantes
| Tabela | Descrição |
|---|---|
| `empresa` | Clientes (empresas contratantes do pentest) |
| `usuario` | Analistas e gerentes do sistema |
| `modelo_pentest` | Templates/modelos de pentest (checklist_id, nome, metodologia, framework) |
| `projeto_usuario` | Tabela pivot: quem está alocado em qual projeto e com qual papel (GESTOR, LIDER, ESPECIALISTA) |
| `vulnerabilidade` | Vulnerabilidades encontradas, vinculadas a um `projeto_id` |
| `checklist` / `checklist_item` | Checklists de segurança |
| `cronometro_registro` | Controle de horas executadas por sessão de pentest |

## 🔒 Padrão de Segurança Adotado no Projeto

### No Controller (sanitização com filter_input)
```php
// CORRETO: usado no ProjetoController (a implementar)
$nome = filter_input(INPUT_POST, 'nome', FILTER_SANITIZE_SPECIAL_CHARS);
$empresa_id = filter_input(INPUT_POST, 'empresa_id', FILTER_VALIDATE_INT);

// ANTIGO (usado em CadastroEmpresaController, não repetir):
$nome = addslashes($_POST['nome'] ?? '');
```

### Na Model (PDO com bindValue — proteção contra SQL Injection)
```php
// CORRETO: sempre usar prepare + bindValue
$sql = $this->pdo->prepare("INSERT INTO projeto (nome, empresa_id) VALUES (:nome, :empresa_id)");
$sql->bindValue(':nome', $dados['nome']);
$sql->bindValue(':empresa_id', $dados['empresa_id'], PDO::PARAM_INT);
$sql->execute();
```
